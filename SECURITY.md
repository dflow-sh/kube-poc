# Security policy

## Supported versions

| Version | Supported |
| --- | --- |
| v0.1.x | Yes |

v0.1.0 is the next release. Fixes are issued for the v0.1.x line. Older tags are not supported.

## Reporting a vulnerability

Report a vulnerability privately through a [GitHub security advisory](https://github.com/dflow-sh/kube-poc/security/advisories/new).

Do not open a public issue for a vulnerability.

## Response

A private report is acknowledged within 3 business days. A further update, including whether the report is accepted, follows within 14 days. A fix for a supported version is coordinated on the advisory before it is made public.
